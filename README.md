## Projects (Assignments) 
- Vehicle Rental System [(link here)](https://github.com/renzuTheBocchi/VehicleRentalSystem-copy)\
  This is me and my teammates' project for the Year 1 Semester 3 **Object-Oriented Programming** course assignment, using **Java**.\
  We chose this Vehicle Rental System as our project title in order to:
  - _apply all the OOP knowledge learnt_, and
  - _have practical experience on OOP code design_.
  - As per project title, this system functions like the vehicle rental websites online, where customers can:
    - Rent cars or motorcycles
    - Customise their rental period
    - Choose their rental package type
  - This system also allow staff to:
    - Manage rentals reserved by the customers
    - Review sales report
  
  - What modules I was in charge of:
    - **<u>Invoice</u>**
      - Generated to customers upon reserving their rentals
      - Includes crucial invoice details, such as rental amount, protection fee, discount, etc.
    - **<u>RentalTransaction</u>**
      - Display customers' rental details, including their name, vehicle details, rental fees
      - Track customers' payment status, e.g. _Pending_, _Completed_, _Failed_
